## 1. Исходная постановка

Нужно нарастить диаграмму классов `Sovereign` **сегментом длящихся связей**, накоплением прецедентов.

Первый якорь членства:

| часть (низ) | целое (верх) | с | смысл |
|-------------|--------------|---|--------|
| Пруссия **ID112** | Германия **ID2** | 1871 | конституционный состав империи |

Оккупация уже описана в сегменте 3 как отдельная иерархия (`PreservingOccupation` / `LiquidatingOccupation`). Вопрос чата: как связать её с «входит в состав» / будущим `SovereignLink`.

## 2. Отклонённые и уточнённые формулировки

### 2.1. Оккупация как подкласс «входит в состав»

Идея: абстракт «входит в состав» (куда, начало, конец) → ветка «просто входит» + ветка «оккупация».

**Почему не принимаем буквально:** уже зафиксировано, что оккупация **не есть** `part_of`.

| Кейс | «Входит в состав»? |
|------|-------------------|
| Пруссия ⊂ Германия с 1871 | да |
| Австрия 1945–55 / Япония SCAP | нет — контроль, не членство в оккупанте |
| Германия ~1945 → ОЗ | нет — ликвидация + новые субъекты-зоны |
| Аншлюс 1938 | нет — `AbsorbLiquidation`, не ребро состава |

### 2.2. Поля «часть» / «общее» на общем предке с оккупацией

Для **членства** пара мереологии удачна, но имя **«общее»** двусмысленно (часто = shared). Лучше **часть / целое**.

Навязывать `часть`+`целое` абстракту, от которого наследует оккупация, снова смешивает мереологию и контроль.

### 2.3. Рабочий вывод к середине обсуждения

- У членства полюса называть **`часть` / `целое`**.  
- Общий предок с оккупацией — **не** «входит в состав» и не мереология.  
- У абстракта отношений оставлять только то, что правда общее (как минимум даты), либо перейти к вертикали (ниже).

## 3. Черновик каркаса (последняя согласованная линия)

### 3.1. Горизонталь / вертикаль

```text
SovereignRelation              <<abstract>>
  valid_from / valid_to

  ├── HorizontalRelation       <<abstract>>   // пока не рассматриваем
  │     (союз, паритет, …)
  │
  └── VerticalRelation         <<abstract>>
        верх  → …               // вышестоящий полюс
        низ   → …               // нижестоящий полюс
          ├── Membership        // «просто входит» / part_of
          └── Occupation        // сегмент 3 встраивается сюда
                ├── PreservingOccupation
                └── LiquidatingOccupation
```

Смысл: «верх / низ» задают **асимметрию направления**, а не утверждение «низ является частью верха».

Синонимы для документации:

| Подкласс | верх | низ |
|----------|------|-----|
| `Membership` | целое | часть |
| `PreservingOccupation` | оккупант(ы) | оккупируемый (жив) |

Формулировку «оккупация ≠ part_of» **сохраняем**: оба — вертикаль, но **разные подклассы**.

### 3.2. Якоря (набросок)

| Кейс | Класс | верх | низ |
|------|-------|------|-----|
| Пруссия с 1871 | `Membership` | `germany` (2) | `prussia` (112) |
| AT 1945–55 | `PreservingOccupation` | союзники | `austria` (111) |
| JP / SCAP | `PreservingOccupation` | USA (или SCAP) | `japan` |
| Аншлюс 1938 | **не** relation | — | `AbsorbLiquidation` |

Слияние / spin-off / absorb по-прежнему живут в `Creation` / `Liquidation`, не в `VerticalRelation`.
