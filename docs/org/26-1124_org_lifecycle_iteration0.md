**Статус:** согласованное направление (2026-11-24); DDL ещё не влит.  
**План чата:** [26-1124_01_org_lifecycle.md](../chat/plan/26-1124_01_org_lifecycle.md)  
**ER Postgres (черновик):** [26-1124_org_lifecycle_er.md](26-1124_org_lifecycle_er.md)  
**Источник каркаса:** `FishEye` / `ags.rgTax*` / особенно `rgTaxReor*` (метафора ЮЛ, не норма международного права).  
**Смежное:** [sovereign_transformation.md](sovereign_transformation.md), [sovereign_class_diagram.md](sovereign_class_diagram.md), эскиз `org_*` (PDF 26-1123), [26-1106_sovereign_relation_discussion.md](26-1106_sovereign_relation_discussion.md).

## 1. Решения

1. **Итерации.** Не проектировать всю модель и классы за один приём. Растить от ЖЦ + правопреемства → прецеденты → длящиеся связи → оккупация / ВС.  
2. **`org` вместо узкого `sovereign`.** Одно лицо учёта для государства, соединения, (позже) коалиционного штаба и т.п. ЖЦ похож; отдельные параллельные схемы избыточны. Различение — лёгким `org_type` (справочник), не отдельными таблицами create/liquidate.  
3. **Основа основ — лицо + справочники kind + таблицы `Reor*`.** Австрия / Чехословакия и аналоги: не «дата ликвидации», а **объект прекращения в форме присоединения с правопреемником**. Без ребра уровня `ReorAcqui` это на данных невыразимо.  
4. **Преобразование (`convert`) — тот же `org.id`.** В ЕГРЮЛ/`rgTaxReorTrans` — два ОГРН; у нас id не меняется, меняются имена (и/или периоды `name_form` у государственных лиц).  
5. **Не в итерации 0:** длящийся состав (`part_of` / SubDivs / Membership), оккупация, горизонтальные союзы, налоговые атрибуты (ИНН, ИФНС, …).  
6. **Онтологии.** Для расплывчатой таксономии терминов — позже как словарь; факты ЖЦ и правопреемства — в SQL. OWL не стартовая платформа (см. README раздела).

## 2. Контуры (не смешивать)

| Контур | Итерация | Примеры |
|--------|----------|---------|
| ЖЦ одного id + **правопреемство** | **0** | create/liquidate kinds; Absorb/Merge/Split/SpinOff edges |
| Имена под id | 0 или 0.5 | полное / краткое × дата (как `rgTaxName*`) |
| Формулы имени государства | уже есть (`name_form`) | отдельный контур UI; не заменять `Reor*` |
| Длящийся состав | 2+ | Пруссия ⊂ Германия; филиал |
| Оккупация / контроль | 3+ | AT 1945–55; не `part_of` и не absorb |

## 3. Что копировать из `rgTax` (урезание)

### 3.1. Брать

| Источник | Роль в `org` |
|----------|----------------|
| `rgTaxMnStRegNum` без налогов/региона | лицо: id, frm_method, frm_date, trm_method?, trm_date? |
| `rgTaxLgEntFrmMtd` | справочник способов создания |
| `rgTaxLgEntTrmMtd` | справочник способов прекращения |
| `rgTaxReorMerge` | слияние: N источников → новый |
| `rgTaxReorAcqui` | присоединение: acquired → acquiring |
| `rgTaxReorDivis` | разделение: divisible → divided |
| `rgTaxReorSepar` | выделение: separable (жив) → separated |
| `rgTaxReorDivisAcqu` / `SeparAcqu` / `DivisMerg` / `SeparMerg` | сочетания (код 6) + промежуточные id |
| `rgTaxName` / `rgTaxNameShort` | имена во времени (0 / 0.5) |

Паттерн целостности источника: FK ребра не только на id лица, но и на **ожидаемый** frm/trm method участника (+ DEFAULT method на колонке ребра).

### 3.2. Не брать в итерацию 0

| Источник | Почему |
|----------|--------|
| `rgTaxReorTrans` как два id | у нас convert = same id |
| `rgTaxSubDivs*` | длящийся состав, не правопреемство |
| ИНН/КПП/ИФНС/регион/физлица/`Buirg`/Reason | налоговый контур |
| обязательная связь с `ags.og` | специфика FEMSQ |

### 3.3. Соответствие формам (очищенно)

| Форма | На лицах | Ребро | Класс (ориентир) |
|-------|----------|-------|------------------|
| Создание с нуля | frm ≈ `1.0` | — | будущий `founded` / create |
| Присоединение | acquired: trm absorb + дата; acquiring жив | Acqui | `AbsorbLiquidation` |
| Слияние | sources: trm merge-out; new: frm merge | Merge | `MergeCreation` + ликвидации |
| Разделение | old: trm split; new: frm split | Divis | `SplitLiquidation` |
| Выделение | parent жив; new: frm spin-off | Separ | `SpinOffCreation` |
| Преобразование | **тот же id**; имена | нет пары id | `convert` |
| Чистая ликвидация | trm liquidate + дата | нет ребра | ликвидация без преемника |
| Сочетания | + промежуточные id | *Acqu / *Merg | как ФНС код 6 |

## 4. Критерий готовности итерации 0

1. DDL в schema `org` (имена таблиц — зафиксировать при реализации) для лица, двух справочников и набора reor-таблиц.  
2. Документированное правило **convert = same id**.  
3. Прецедент на данных: Австрия (или учебный стенд) — прекращение **присоединением** с указанием правопреемника, а не только датой.  
4. Явный анти-список: нет Membership/occupation в этих таблицах.

DDL и seed — по плану чата; class-диаграмму синхронизировать с реляцией, не блокировать ею DDL.
