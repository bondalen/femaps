# Глоссарий раздела `org`

Кратко: термины модели суверенов и основ официальных имён.  
Подробности и алгоритм представления — в [README.md](README.md).

---

## A. Сущности учёта

| Термин | EN / код | Смысл |
|--------|----------|--------|
| **Суверен** | sovereign | Государство (или иной корневой субъект учёта) как **стабильная сущность**: Япония, Германия, Франция. Смена формулы имени не обязана порождать нового суверена. Жизненный цикл id — см. [sovereign_transformation.md](sovereign_transformation.md). |
| **Событие трансформации суверена** | sovereign_event | Факт на дату из закрытого перечня (`merge`, `absorb`, `split`, `spin_off`, `convert`, сочетания, `create`, `dissolve`), задающий правопреемство корней учёта. |
| **Основа имени** | name form | Абстрактный тип официальной формулы в титуле: республика, королевство, рейх, empire, государство… **Не** само государство. |
| **Период формулы** | sovereign_name_form | Связь суверена с основой имени на интервале `[valid_from, valid_to]`. Лист в дереве представления. |
| **Ярлык основы** | name_form_label | Строка основы имени в языке UI: `Staat`, `empire`, `рейх`. |
| **Полное официальное имя** | (планируется sovereign_name) | Титул экземпляра: «Großdeutsches Reich», «Dai-Nippon Teikoku». Не путать с ярлыком основы. |
| **Назначаемая основа** | assignable | Основа, которую допустимо ставить суверену в периоде. Неназначаемая — только группировка в UI (если введут). |

## B. Граф и представление

| Термин | Смысл |
|--------|--------|
| **Смысловое ребро** | Один факт «родитель → потомок» между основами (`empire → reich`). Не дублируется на каждый язык. |
| **Метка языка на ребре** | Язык, для которого ребро **явное** в UI (целевая таблица `name_form_edge_label`; в схеме `010` временно `language_code` на ребре). |
| **Явное ребро (в языке L)** | Ребро с меткой L: в UI L этот шаг рисует дочерний узел как ветку (при прочих правилах). |
| **Туннель** | Ребро **без** метки L при построении дерева L: обход продолжается, промежуточный узел может не показываться. |
| **Ближайший показанный предок** | Узел UI, под которым рисуется скрытый потомок или лист суверена после свёртки туннелей. |
| **Дерево представления** | Вычисляемое для языка L дерево веток (`name_form`) и листьев (`#n` периоды). Не хранится как отдельная иерархия суверенов. |
| **DAG основ** | Объединение смысловых рёбер; допускает несколько путей (напр. к `kingdom`). В одном языке UI сводится к дереву правилами выбора пути. |
| **Структурный номер** | Вычисляемый адрес в дереве UI (`1.1`, `1.1.#2`). Не идентификатор в БД. |
| **Свёртка** | Показ суверенов «невидимых» в L основ под видимым предком (напр. периоды с `reich` под `empire` в en). |

## C. Основы имени (рабочий набор v0)

Коды — кандидаты для seed; ярлыки уточняются при заливке.

| code | RU | DE (типично) | EN (типично) | Заметка |
|------|----|--------------|--------------|---------|
| `state` | государство | Staat | state | Корень представления; нейтральная формула (в т.ч. послевоенная Япония). |
| `empire` | империя | Empire / (часто не этаж UI) | empire | Шире, чем `reich`; полка en для свёртки. |
| `reich` | рейх | Reich | Reich | Уже, чем `empire`; формула *Deutsches / Großdeutsches Reich*. |
| `kaiserreich` | кайзеровская империя | Kaiserreich | (свёртка в empire) | Отдельно от голого `reich` для de. |
| `kingdom` | королевство | Königreich | kingdom | В de часто под `reich` словообразовательно; в en — ветка от `state`. |
| `republic` | республика | Republik | republic | |

*Kaiserreich* и *Königreich* в немецком делят корень *Reich* — это **лексика**, не повод делать `kingdom` потомком `reich` в смысле «все королевства мира ⊂ рейх». Ребро `reich → kingdom` в de-проекции — осознанный display/морфологический выбор, документируемый метками, не универсальный закон.

## D. Различения (частые путаницы)

| Не смешивать | Почему |
|--------------|--------|
| Суверен ↔ основа имени | Япония одна; `empire` / `state` — периоды формулы. |
| Основа имени ↔ режим | «Империя» в титуле ≠ оценка политического режима. |
| Основа имени ↔ полное имя | `reich` ≠ строка «Großdeutsches Reich». |
| Ярлык основы ↔ ярлык суверена | `name_form_label` vs будущее имя государства по языкам. |
| Смысловое ребро ↔ дерево UI | Одно ребро в данных; разные деревья de/en из алгоритма. |
| Состав ВС ↔ управление | Позже: дерево принадлежности vs DAG подчинения; не путать с основами имён. |
| Суверен ↔ коалиция | SHAEF / Expeditionary Force — не государство; отдельный класс организаций. |
| `reich` ↔ `empire` | Связаны как «уже / шире» на смысловом уровне; в UI en часто виден только `empire`. |
| `convert` ↔ новый `sovereign` | Смена формулы имени (Япония 1947) — тот же суверен; новый id только при split/spin_off/merge/create и т.п. |
| Реорганизация суверена ↔ перекройка территории | Границы без прекращения субъектов — вне enum трансформаций. |

## E. Примеры якорей (для seed / тестов)

| Суверен (code) | Период (ориентир) | name_form | Ожидание UI (схема туннелей) |
|----------------|--------------------|-----------|------------------------------|
| `japan` | 1889-11-29 … 1947-05-02 | `empire` или `kaiserreich`* | en: под empire; de: под Kaiserreich, если якорь `kaiserreich` |
| `japan` | 1947-05-03 … | `state` | под Staat / state |
| `germany` | 1871-01-18 … 1918-11-09 | `kaiserreich` | de: под Kaiserreich; en: под empire (свёртка) |
| `germany` | … … 1945-05-08 | `reich` | de: под Reich; en: под empire |
| `france` | упрощённо III→… | `republic` | под republic / Republik |

\*Для de-эскиза с Dai-Nippon под Kaiserreich предпочтителен якорь `kaiserreich`; иначе период на одном лишь `empire` в de может подняться к `Staat`.

Даты — ориентиры модели, не замена источниковедческой хронологии.
