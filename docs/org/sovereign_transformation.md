# Трансформации суверена: закрытый перечень по аналогии с реорганизацией ЮЛ

**Источник аналогии (не норма проекта):** ст. 57–58 ГК РФ; ст. 50 НК РФ; пояснения ФНС о формах реорганизации и сочетаниях форм  
([nalog.gov.ru — реорганизация](https://www.nalog.gov.ru/create_business/ul/closing/restructuring/), сервис госрегистрации ФНС).  

**Статус:** рабочая модель для раздела `org`. Юридический перечень ЮЛ — **метафора правопреемства и жизненного цикла**, не претензия на налоговое или международно-правовое равенство государства и ООО.

См. также: [README.md](README.md), [glossary.md](glossary.md), [sovereign_class_diagram.md](sovereign_class_diagram.md) (схема классов).

## 1. Закрытый перечень форм реорганизации ЮЛ

Пять базовых форм (п. 1 ст. 57 ГК РФ; те же формы различает ст. 50 НК РФ по налоговому правопреемству):

| # | Форма | Что происходит с лицами | Правопреемство (смысл для учёта) |
|---|--------|-------------------------|----------------------------------|
| 1 | **Слияние** | Несколько лиц → **одно новое**; исходные прекращаются | Универсальное к вновь возникшему |
| 2 | **Присоединение** | Одно (или несколько) → **уже существующему**; присоединяемые прекращаются | К присоединившему (продолжающему) лицу |
| 3 | **Разделение** | Одно → **несколько новых**; исходное прекращается | К вновь возникшим (по передаточному акту / долям) |
| 4 | **Выделение** | Из состава → **одно или несколько новых**; исходное **продолжает** существовать | Частичный переход по акту; исходное остаётся |
| 5 | **Преобразование** | Смена организационно-правовой формы; в гражданском смысле — новое лицо той же «линии», иная ОПФ | Правопреемник — вновь оформленное лицо той же непрерывности обязательств |

Допускается **одновременное сочетание** форм (ст. 57 ГК РФ). В разъяснениях ФНС явно называют, в частности:

| Сочетание | Смысл |
|-----------|--------|
| Разделение + присоединение | Части разделённого лица сразу входят в уже существующие лица |
| Выделение + присоединение | Выделяемая часть сразу присоединяется к уже существующему лицу |
| Разделение + слияние | Части уходят в одно или несколько **новых** лиц, образованных слиянием |
| Выделение + слияние | Выделяемая часть входит в **новое** лицо, создаваемое слиянием |

**Вне** реорганизации, но нужны для полного жизненного цикла учёта:

| Событие | Смысл |
|---------|--------|
| **Создание** | Появление лица «с нуля» (не из реорганизации) |
| **Ликвидация** | Прекращение **без** правопреемника по составу (в налоговом контуре — отдельный режим; для суверена — см. §3) |

## 2. Два контура: жизненный цикл vs связи

Главное различение (кейс Австрия / Германия / Австро-Венгрия):

| Контур | Где живёт | Когда применять |
|--------|-----------|-----------------|
| **Жизненный цикл одного лица** | Создание на `sovereign`; **ликвидация — объект** (см. схему классов, сегмент 1) | Прекращение через абстрактный `Liquidation` и подклассы, не через флаги на строке |
| **Связи между лицами** | Отдельная таблица рёбер с датами | Пока **оба** существуют и одно входит в другое (состав), либо иные длящиеся отношения |
| **Имена / формулы** | `sovereign_name_form` (+ позже полные имена) | Периодическая смена титула **без** смены id |

### 2.1. Правило «поглощение ≠ связь»

Пример: Австрия `ID1` в 1938 присоединяется к Германии `ID2`.

- У `ID1` объект `AbsorbLiquidation`: `date = 1938`, `absorber = ID2`.
- **Строку связи `ID1 → ID2` не создаём** — факт поглощения в объекте ликвидации.
- `ID2` продолжает жить.

Пример: до 1918 Австрия `ID1` — составная часть Австро-Венгрии `ID3`.

- Оба id живы в пересечении дат → нужна **связь** `part_of` (`ID1` → `ID3`) с датами (сегмент связей — позже).
- В 1918 у `ID3` объект `SplitLiquidation` + разделители (`SplitAllotment`: `parts` + `recipient`); `ID1` **не** ликвидируется. Ликвидация `ID1` — отдельно, в 1938 (`AbsorbLiquidation`).

### 2.2. Сегмент 1: иерархия ликвидации (зафиксировано)

См. [sovereign_class_diagram.md](sovereign_class_diagram.md).

| Класс | Поля / связи |
|-------|----------------|
| `Liquidation` (abstract) | `date` |
| `AbsorbLiquidation` | `absorber` → `Sovereign` |
| `SplitLiquidation` | коллекция `SplitAllotment` |
| `SplitAllotment` | `parts` (что отошло); `recipient` → `Sovereign` |

У `Sovereign` композиция `0..1` `Liquidation`. Смена имени / `name_form` — **не** ликвидация.

### 2.2b. Сегмент 2: иерархия создания (зафиксировано)

| Класс | Поля / связи |
|-------|----------------|
| `Creation` (abstract) | `date` |
| `SpinOffCreation` | `source` → `Sovereign` (выделение; кейс Австрия **ID111**) |
| `MergeCreation` | коллекция `MergeSource` |
| `MergeSource` | `contributor` → `Sovereign`; опционально `parts` (кейс ФРГ ← 991+992+993) |

У `Sovereign` композиция **1** `Creation` и **0..1** `Liquidation`. Иные подклассы создания — по кейсам.

### 2.2c. Сегмент 3: оккупация (зафиксировано)

| Класс | Смысл | Кейс |
|-------|--------|------|
| `Occupation` (abstract) | `valid_from` / `valid_to` | — |
| `PreservingOccupation` | оккупируемый `Sovereign` **сохраняется** | Австрия 1945–1955; Япония 1945–1952 |
| `LiquidatingOccupation` | оккупируемый **ликвидируется**; зоны → отдельные `Sovereign` | Германия ~1945 → ОЗ → ФРГ (`MergeCreation`) |

Оккупация не заменяет создание/ликвидацию и не есть `part_of`.

### 2.3. Связи `sovereign_link` (длящийся граф)

| Поле | Смысл |
|------|--------|
| `src_sovereign_id` | Член / подчинённый по смыслу ребра |
| `dst_sovereign_id` | Целое / вышестоящий |
| `link_type` | Минимум для кейса: `part_of` (составная часть). Дальше — только от реальных случаев |
| `valid_from` / `valid_to` | Интервал, пока связь действует |

Связь не заменяет ликвидацию: обрыв `part_of` в 1918 ≠ ликвидация Австрии.

### 2.4. Ориентиры id (документальная линия)

| id | code | Создание | Ликвидация |
|----|------|----------|------------|
| 111 | `austria` | `SpinOffCreation` (после ВМВ **не** merge ОЗ; см. схему) | 1938 `AbsorbLiquidation` → `germany` |
| 2 | `germany` | позже | ~1945; **≠** `frg` |
| 3 | `austria_hungary` | позже | 1918 `SplitLiquidation` |
| 991–993 | `oz_*` | позже | при вхождении в ФРГ |
| *новый* | `frg` | `MergeCreation` ← 991+992+993 | — |

Разрыв без германского государства между концом `germany` и `frg`.

### 2.5. Что наращивать дальше

`source` Австрии 111; ликвидация `germany` / рождение ОЗ; ликвидация ОЗ при merge; `founded`; имена; `SovereignLink`.

## 3. Порядок использования (как вести учёт)

1. **Появление** → объект `Creation` (`SpinOffCreation` / `MergeCreation` / …).  
2. **Прекращение** → объект `Liquidation` (`AbsorbLiquidation` / `SplitLiquidation` / …).  
3. **Имя / длящаяся входимость** — отдельные сегменты.  
4. **Не** Continuity `germany`→`frg` одним id; **не** подменять merge/spin-off рёбрами `SovereignLink`.  
5. **DDL** — после сегментов: [sovereign_class_diagram.md](sovereign_class_diagram.md).

---

## 4. Анти-двойной счёт (связь с планом ВС)

Как в налоговом учёте один долг не считают дважды у предшественника и преемника на одну дату:

- на дату D суверен либо **активен**, либо **закрыт**;  
- после `absorb`/`merge` численность/оргсостав листьев `part_of` считается только под выжившим/новым корнем;  
- `convert` не дублирует корень.
