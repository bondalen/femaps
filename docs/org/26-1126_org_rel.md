## 1. Объём v0

| Входит | Не входит |
|--------|-----------|
| `part_of` (часть ⊂ целое), оба `org` существуют | `org_reor_*` (Absorb/Separ/…) |
| интервал с nullable границами + **effective** | Occupation / союзы |
| прецедент `moscow` ⊂ `vladimir` | полный граф Орда/ВКЛ без их id |

Имя таблицы: **`org.org_rel`**. Тип связи: колонка `rel_type`, первое значение **`part_of`**.

---

## 2. Таблица

```text
org_rel
  id           bigserial PRIMARY KEY
  part_id      bigint NOT NULL  → org.org   -- низ / часть
  whole_id     bigint NOT NULL  → org.org   -- верх / целое
  rel_type     text NOT NULL DEFAULT 'part_of'
  valid_from   date NULL          -- NULL → effective start
  valid_to     date NULL          -- NULL → effective end / открыто
  note         text
  created_at   timestamptz NOT NULL DEFAULT now()

  CHECK (part_id <> whole_id)
  CHECK (valid_to IS NULL OR valid_from IS NULL OR valid_to >= valid_from)
  UNIQUE (part_id, whole_id, rel_type)   -- v0: один интервал на пару+тип
```

Календарь дат — **вариант A** (ER ЖЦ §4.2): колонки григорианские.

---

## 3. Effective-интервал

Хранимые `valid_from` / `valid_to` — явные сужения. Если NULL:

| Поле | Effective |
|------|-----------|
| `valid_from` IS NULL | `greatest(part.frm_date, whole.frm_date)` |
| `valid_to` IS NULL | `least(part.trm_date, whole.trm_date)` среди **не-NULL** trm участников; если оба trm NULL — конец **открыт** (NULL) |

VIEW `org.org_rel_effective` отдаёт `eff_from` / `eff_to` для запросов.

Явная граница не должна выходить за жизни участников (правило доки; жёсткий триггер — позже).

| Ситуация | Модель |

| Оккупация SCAP / AT 1945 | не v0 |
