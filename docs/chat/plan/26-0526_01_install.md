### 6.3. Кандидаты на следующие пилоты (поиск более качественного и быстрого)

Оценка для **оранжевых линий ж/д Lage West 1:1M** в ячейке 1°×1°:

| Приоритет | Метод | Среда | Почему перспективен | Риск / ограничение |
|-----------|-------|-------|---------------------|-------------------|
| **1** | **Цветовая сегментация + скелетизация** (HSV/RGB маска оранжевого → morphology → skeleton → вектор) | WSL OpenCV + `ogr2ogr` / QGIS GRASS `r.thin` | Ж/д на Lage West имеют **устойчивый оранжево-коричневый** цвет; батч по всей ячейке; воспроизводимый пайплайн ([Gede et al., AVHM](http://lazarus.elte.hu/avhm/proc/AVHM_proceedings_04_Gede_etal.pdf)) | Шум: рельеф, подписи, сетка; нужна фильтрация по ширине/длине; класс (`fd_express`/`multi`) — отдельно по засечкам |
| **2** | **GeoOSAM** → маска полосы → medial axis / skeleton → LineString | QGIS (установлен) | Точечный клик по линии; режим «похожие объекты» / Detect по ROI; уже в стеке проекта | Полигон, не линия — нужен пост-процесс centerline; SAM путает параллельные линии и шум |
| **3** | **segment-geospatial (samgeo)** — скрипт по клипу ячейки | WSL venv `/home/alex/venvs/maps` | Пакетная обработка, Jupyter, повторяемость; интеграция с GeoPandas → PostGIS | Требует GPU/CPU время; те же проблемы zero-shot SAM на 1:1M |
| **4** | **AutoTracer** (QGIS) | QGIS plugin | Готовый pipeline: binarization → skeleton → vector | Нужна предварительная цветовая маска; плагин новый, проверить на QGIS 3.44 |
| **5** | **Deepness** (ONNX, DirectML) | QGIS + AMD GPU | Батч по тайлам, ускорение на Radeon 780M | Модели под современные снимки/OSM-стиль; для исторической 1:1M — только после **своей** модели или fine-tune |
| **6** | **MapSAM / MapSAM2** | Python (исслед.) | Специализация на исторических картах, датасет ж/д Siegfried ([GitHub](https://github.com/Xue-Xia/MapSAM)) | Стиль швейцарских топокарт ≠ Lage West; нужна адаптация / разметка |

- **ArchaeoTrace:** пилот выполнен (§6.2); для ж/д 1:1M — вспомогательный вариант; патчи плагина в `%APPDATA%\\QGIS\\...` сбросятся при обновлении — задокументировать в репозитории при необходимости.
- **PostGIS для ArchaeoTrace:** скрипты `002`–`004` в `scripts/sql/`; при смене ячейки обновить триггер и DEFAULT.
