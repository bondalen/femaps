## 0. Цель

**Фаза A (текущий фокус):** стабильный учёт **суверенов** и **основ официальных имён** (`name_form`) с языковыми деревьями представления (de / en / …) по алгоритму туннелей из `docs/org`.

**Фаза B (после закрытия A):** реляционный DAG **состава** и **управления** ВС / коалиций на тех же суверенах (пилот Запад / SHAEF 1944).

### Критерий закрытия фазы A

Запросом к БД для языка L (и опционально даты) получается дерево, согласованное с эскизом [26-1102](../../org/26-1102_presentation_sketch.md):

1. Ветки `name_form` с учётом явных рёбер и туннелей.  
2. Листья периодов (`sovereign_name_form`) на ближайшем показанном предке.  
3. en/ru не показывают `reich` / `kaiserreich` / `kaisertum` как ветки; de: `Staat → Kaisertum | Reich → Kaiserreich | Königreich | Republik`.

### Критерий закрытия фазы B (и чата в целом по исходному замыслу)

Запросом на дату (напр. `1944-12-01`):

1. Дерево **состава** от суверена до выбранного уровня.  
2. DAG **управления** (в т.ч. коалиционный штаб → национальные армии).  
3. Отличие «принадлежит Heer» от «оперативно под SHAEF / OB West».  
4. Нет двойного счёта одной единицы в двух корнях состава.

### Вне scope (весь чат)

| Область | Почему |
|---------|--------|
| Геопривязка, полосы, Martin / QGIS-слои оргструктуры | После стабилизации справочника |
| Полное гражданское дерево | Не нужно для учёта ВС |
| Партия / Allgemeine SS как гражданский слой | Только вооружённые «равные гос.», если появятся на ТВД |
| Онтологии OWL/RDF, Fuseki | Только если реляция упрётся (узел **1.3.2**) |
| Персоны | Позже |
| Массовый Soll/Ist | Поля можно зарезервировать в B; ввод — не цель |
| UI-приложение поверх деревьев | Достаточно SQL / VIEW / функции |

## 3. Модель данных

### 3.1. Фаза A — факт и цель (`docs/org`)

**В БД (`010`+`011`+`012`):** смысловое ребро + `name_form_edge_label`; seed v0 по [1102](../../org/26-1102_presentation_sketch.md).

| Таблица | Роль |
|---------|------|
| `org.language` | языки ярлыков |
| `org.name_form` | абстрактная основа имени |
| `org.name_form_label` | ярлык основы × язык |
| `org.name_form_edge` | parent→child **без** `language_code` |
| `org.name_form_edge_label` | языки явного шага UI |
| `org.sovereign` | суверен учёта |
| `org.sovereign_name_form` | суверен × основа × `[valid_from, valid_to]` |

Алгоритм туннелей — README §4; канон рёбер — 1102 §1.

Принципы: основа имени ≠ государство ≠ полное официальное имя; UI-дерево относительно языка; AT=`kaisertum` не под `reich`; JP/RU=`kaiserreich` под `reich` в de.

### 3.2. Фаза B — ВС / коалиции (спека, DDL после 1.1.3.2)

| Сущность | Назначение |
|----------|------------|
| `org_system` | Heer, Luftwaffe, US Army…; `coalition` для надгосударственных штабов |
| `org_kind` | ministry_mil, high_command, army_group, army, corps, division, expeditionary_force, combined_hq… |
| `org_template` | типовой шаблон (KStN-класс); `external_code` опционально |
| `organization` | «7. Armee», «21st Army Group», «SHAEF» |
| `org_name` | исторические / языковые имена |
| `org_link` | `src` → `dst`, тип связи, интервал дат |

| `link_type` | Граф | Смысл |
|-------------|------|--------|
| `part_of` | Состав | Жёсткая принадлежность (дерево/лес) |
| `commands` | Управление | Оперативное подчинение (DAG) |
| `attached_to` | Управление | Придано / временно подчинено |
| `coalition_member` | Коалиция | Участник коалиционного штаба (≠ `part_of`) |

Анти-двойной счёт: численность = листья по `part_of`; рёбра управления/коалиции людей не добавляют.

Коалиции — обычные `organization` (`combined_hq` / `expeditionary_force` / система `coalition`): национальная армия остаётся в своём `part_of`; связь с SHAEF — `commands` / `coalition_member` на дату.

**Dual-hat (OB West / HGr D)** — выбрать в **1.2.2**: (1) две организации + `same_staff_as`, или (2) одна организация состава + второе `commands` с ролью `dual_hat`. Для пилота предпочтителен (2).

```text
org.*     -- этот чат
public.*  -- railways и пр. (не трогаем)
```

## 5. Риски и правила ведения

**Фаза A**

1. Не смешивать суверен, основу имени и полное официальное имя.  
2. Не вводить англичанам ветки `reich` / `kaiserreich` в UI-дереве.  
3. Не добавлять `state → reich` «для de», если туннель через `empire → reich` даёт нужную проекцию.  
4. История формулы имени — новые интервалы `sovereign_name_form`, не затирать `valid_to`.

**Фаза B**

5. Не смешивать `part_of` и `commands` в одном «parent_id».  
6. Не класть коалиционный штаб внутрь национального `part_of` как корень численности.  
7. Суверен ≠ коалиция (SHAEF).  
8. Расширение вниз до дивизий — по нужде пилота, не «весь Heer 1944».  
9. Онтологии — план B (узел 1.3.2), не параллельный трек.
